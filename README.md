## 🚀 How to Run the Projects

To review or run a specific laboratory work, clone the repository and switch to the corresponding branch:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd YOUR_REPO_NAME
   ```

2. **Check available branches:**
   ```bash
   git branch -a
   ```

3. **Switch to a specific lab branch:**
   ```bash
   git checkout lab-1-04-09-2026
   ```

4. **Compile and run via terminal:**
   ```bash
   javac -d out src/Main.java
   java -cp out Main
   ```
   *(Or simply open the project folder in IntelliJ IDEA).*
