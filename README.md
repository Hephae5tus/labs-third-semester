## 🐍 Contribution Snake

GitHub doesn't generate this automatically — it's produced by a GitHub Action that
snapshots your contribution graph into an animated SVG. Add this workflow at
`.github/workflows/snake.yml` in your profile repo (a repo named exactly `Hepha3stus`)
and it will start rendering for real:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: Hepha3stus
          outputs: dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
